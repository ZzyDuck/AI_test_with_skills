## 失败用例详情

### 1. TC-HOME-008: 搜索框超长输入

**问题描述**:
搜索框未对输入长度进行限制，允许输入超过100个字符。

**预期结果**:
输入被截断或提示超出长度限制

**实际结果**:
输入未被截断，允许超过100个字符

**错误信息**:
```
AssertionError: expected 150 to be <= 100
```

**严重程度**: 中

**建议修复**:
1. 在前端输入框添加 maxlength 属性限制输入长度
2. 添加输入长度验证逻辑
3. 当输入超过限制时显示友好提示

---

### 2. TC-HOME-009: 页面刷新后Tab状态保持

**问题描述**:
页面刷新后，之前选中的Tab状态未被保持，默认回到第一个Tab。

**预期结果**:
保持金库待审批Tab选中

**实际结果**:
页面刷新后Tab状态未保持

**错误信息**:
```
AssertionError: expected '' to contain 'active'
```

**严重程度**: 中

**建议修复**:
1. 使用 localStorage 存储当前选中的Tab状态
2. 或者使用 URL 参数传递Tab状态
3. 页面加载时读取保存的状态并设置对应Tab为激活状态
